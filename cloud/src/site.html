LyricDock

A phone on your desk that becomes a Spotify lyrics dock: word-synced lyrics, the album art, controls. This domain hosts the dock's cloud helpers.

Source on GitHub

Cover API

Base URL https://art.lyricdock.losthusky.qzz.io. Album details and Apple Music’s animated covers, looked up once and indexed. Open CORS; plain GET.

GET /v1/coverartist, album, px (size needed), hevc=1, shape=square|tall, q=max → still image + the best-fitting animated cover video
GET /v1/albumartist, album → album details, colours, editorial notes, every video variant, track list
GET /v1/trackartist, album, title → one track's details
GET /v1/healthis it up
curl "https://art.lyricdock.losthusky.qzz.io/v1/cover?artist=Gorillaz&album=Plastic%20Beach&px=1080"

Personal, non-commercial project. Artwork and metadata belong to their owners and come from Apple's public catalogue.
