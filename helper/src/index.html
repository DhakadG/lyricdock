Phone

Install the app on the phone

Normal appDownload the APK on the phone and open it. No cable needed.
Dedicated dock (kiosk)Full screen, starts on boot, updates silently. One time, over USB.
  1. Remove all accounts from the phone (Settings → Accounts) or use a factory-reset phone.
  2. Settings → About phone → Software information → tap Build number 7 times.
  3. Settings → Developer options → turn on USB debugging, connect the cable.
  4. Click Run phone setup and tap Allow on the phone when asked. adb is downloaded temporarily and deleted afterwards.

Pair

The phone shows a code like K7QX-9MP-2F2. In Spotify click the LyricDock button in the top bar → Pair phone, type it, click Pair. Once per phone.

Connection

Spotify and the phone connect directly over your network. If your Wi-Fi blocks devices from reaching each other, turn on USB tethering on the phone (cable connected) and set the phone's Settings → Connection → Connection path to Prefer USB cable.

How it works

LyricDock is a Spicetify extension plus an Android app. Spotify sends the playing track, lyrics and position straight to the phone over your network; the phone sends play, pause, skip, seek and like back. This helper only installs and checks things - you can close it.
